# 1、选题

结合本课程学习，选择任意的AI辅助开发工具，从以下题目中任选一个课题，完成需求拆解、系统设计和开发工作，并编写课程设计文档、参加答辩。

【Web开发类】

1、弹幕视频网站的设计与开发（参考：bilibli弹幕网）

2、微博客社交平台的设计与开发（参考：微博电脑版）

【App开发类】

3、笔记社交APP的设计与开发（参考：小红书APP）

4、二手交易APP的设计与开发（参考：闲鱼APP）

【游戏开发类】

5、任意游戏的设计与开发（不限主题，但需要有完整的核心玩法流程）

【AI创意类】

6、AI小说创作平台的设计与实现（无参考，需要借助AI完成小说的创作、修改、完善、发布，并支持小说分类和阅读，根据功能和细节进行评分）

7、AI图片/视频创作平台的设计与实现（无参考，根据功能和细节进行评分）

# 2、评分标准

| **考核**内容                                           | **评分权重** |
| ------------------------------------------------------ | ------------ |
| 提示词设计：包括系统提示词、开发规划、调试提示词设计   | 20%          |
| 需求分析：重点考查需求是否完整、全面、符合实际         | 20%          |
| 技术选型和架构设计：考查技术方案、代码结构、可维护性   | 10%          |
| 系统运行情况：考查系统功能是否完整、系统运行是否正常   | 10%          |
| 答辩表现：系统演示情况、讲解是否流畅、能否正确回答问题 | 20%          |
| 文档质量：文档内容是否完整、格式是否美观、截图是否丰富 | 10%          |
| 创新性：是否解决了实际问题或具有有趣的功能特性         | 10%          |
| 合计                                                   | 100%         |
